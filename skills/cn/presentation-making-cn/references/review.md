# 质量检视与重构

按下表查实物和来源，记录具体缺陷、影响页、修正及复验结果。分数和“整体不错”不能代替证据。

| 维度 | 可观察的通过条件 | 失败时回到哪里 |
| --- | --- | --- |
| 事实 | 关键主张可定位到来源；推断、假设与案例性质明确；数字、限定词和口径一致 | 理解材料；补证或收窄主张 |
| 承诺 | 正文支持开场承诺；结尾能指出已获得的能力、认识或判断依据 | 塑形；必要时重新确认目标 |
| 理解 | 前置概念先于使用；相近概念有关键区分；章节接缝说明认知进展 | 大纲；补桥接、近似反例或调整顺序 |
| 记忆 | 一句话可复述核心；抓手能引回主张及依据；回扣提供不同角度；结尾强化所得 | 塑形或大纲；更换抓手、删竞争主张 |
| 节奏 | 总时长包含互动与过渡；重点有解释空间；超时可删内容不破坏主线 | 大纲；取舍或调整范围 |
| 页面 | 正文适合场景，备注足以支撑讲述；图表关系和来源可读，无占位或错误链接 | 创作；拆页、修图、补备注 |
| 可用性 | HTML 各页与交互状态已实际查看；或 Markdown 分页、备注、资产与所选渲染器行为已检查 | 创作；修复后重验 |

## 两次内容视角

**陌生听众**：只依据观众能看到的正文和将听到的备注，标出首次遇到却未解释的术语、论证跳步、误解风险和注意力过载。模拟仅是缺陷查找，不等同真实用户测试。

**回忆路径**：读开场、关键回扣与结尾，用一句话复述核心，并指出哪个抓手能带回哪条依据。若只能复述标语，补回意义；若只能列出很多主题，收敛主张；若记住的是未经证实的数字，修复事实与抓手。

## 修复闭环

先处理事实错误和方向偏差，再处理理解与记忆，最后修视觉细节。追溯最早失效阶段，修改受影响页面、备注与记录；跨页主张改变时重新核对全篇承诺和收束，局部布局改动复验相关页面及导航。

继续修复可在当前范围解决的问题，直到各项通过。改变目标或超出已有授权的重大方向变化进入对齐；缺材料或工具时列出具体阻塞、已完成部分和下一步，明确产物是待验证草稿。不要无限循环润色，也不要将尚未验证的结果宣布为高质量成品。

交付说明只需：成品路径；听众所得与记忆设计的一句话；检查结果与真实限制。工作记录保留详细依据，成品中不展示内部评分或方法标签。
