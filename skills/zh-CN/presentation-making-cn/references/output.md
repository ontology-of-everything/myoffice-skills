# 输出约定

只制作用户选择的 HTML 或 Markdown。默认 HTML、现场演示配讲者备注；完整阅读模式增加理解所需正文。用户模板和品牌约束优先；默认清晰、克制，视觉层级服务论证。

## 共同内容

每页一个主要职能；主张页以可理解的结论作标题，提问页可以保留问题。正文承载听众此刻需要看的内容；备注承载解释、证据细节、过渡、互动和时间提示。来源在相关页就近短标注，完整出处放备注或参考页，避免挤成不可读小字。

用图形表达比较、因果、流程和层级，而非填满空白。数量图保留单位、基线、时间范围和数据来源；类比图明确它是类比。页面重排保留稳定 ID，标题改变不改变身份。

## HTML

- 交付可直接打开的单文件 `.html`，内嵌 CSS、必要的少量导航 JavaScript 与使用中的资产；默认系统字体，无联网加载依赖。
- 优先使用语义化 HTML 与 SVG 构建清晰页面。按目标显示尺寸设计，保持可读字号与间距，长内容拆分或移到备注，不靠无限缩小字号容纳。
- 提供前后页按钮、方向键导航、页码和清晰焦点；备注默认隐藏且可明确切换。编辑输入区域时导航快捷键不抢占输入。
- 渐显仅用于逐步解释或延迟揭示答案。处理首页、末页、页内步骤和返回路径；尊重减少动态效果偏好。
- 互动题的答案在备注或后续揭示状态，初始观众视图不暴露答案。交付的是源码可见文件，隐藏备注不是保密措施。
- 用可用浏览器实际打开，检查每页及有意义的渐显状态；测试导航、备注切换、目标窗口下的溢出和可读性。无法运行时报告未验证项。

本技能不附带生成脚本；成品内必要的交互代码不构成运行技能的依赖。

## Markdown

默认使用可移植逐页 Markdown，以 `---` 分页。格式示例：

```markdown
<!-- slide: decision-boundary -->
# 先验证瓶颈，再扩大试点

完整页正文，包括必要图表、证据或清楚的示意图。

来源：材料名称与位置。

<!-- notes
讲者备注：解释依据与限制。
过渡：从证据转向应用。
互动：向观众提问；等待；预期答案；无人回答时的接法。
预计时间：根据实际内容估计。
-->

---
```

示例是结构，不是固定句式。交付前填实内容，不能遗留占位说明。使用 HTML 注释隔离备注；原始源码仍可见。未经验证，不保证特定 Markdown 渲染器的演示功能或保密性。

必要图像默认用内联 SVG、文本示意或用户已提供资产；使用本地资产时一并交付并核对链接。用户选择特定渲染器后遵循其语法并实际验证，不能把普通 Markdown 冒称已验证的幻灯片应用。
