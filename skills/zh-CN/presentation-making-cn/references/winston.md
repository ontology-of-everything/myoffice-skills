# Winston 原则与必要范式

依据 Patrick Winston 的 MIT《How to Speak》思想进行演示制作适配。原讲述提供启发式，不是经本技能验证的记忆定律。下面的阶段映射、输出约定和验收办法是工程化扩展。

## 六项原则：含义、落点与反例

| 原则 | 定义与落点 | 正例 | 反例 |
| --- | --- | --- | --- |
| Empowerment promise／赋能承诺 | 塑形时确定听众所得；开场说清，结尾兑现 | “结束后，你能用三项指标判断一个试点是否值得扩大。” | “今天介绍我们的完整方案。”只有主题，没有所得 |
| Cycling／多角度回扣 | 大纲中让核心经由解释、实例、应用再次出现 | 先解释等待环节，再看流程案例，最后用同一方法诊断新案例 | 每隔几页原样重复标语 |
| Fence／概念围栏 | 在可能混淆处展示关键区别，必要时使用近似反例 | “缓存复用旧结果，批处理合并新请求；两者降低开销的路径不同。” | “我们今天不讨论数据库。”只限定范围 |
| Verbal punctuation／口头路标 | 在结构接缝回顾已建立的认识并引出下一问题 | “我们已找到等待发生的位置；接下来判断哪些等待可以消除。” | “下面进入第二部分。”缺少认知连接 |
| Ask and wait／提问并等待 | 在理解关键点让听众预测、判断或应用；备注保留等待与接法 | “这两种改动，哪种会缩短总耗时？”停顿后再揭示依据 | 提问同时显示答案，或问只有讲者知道的内部事实 |
| Ending／收束 | 将兑现的所得与记忆抓手留给听众；行动请求取决于目标 | 回到三项判断指标，让听众带走可应用的判断方法 | 新增未经铺垫的大主张，或仅留“谢谢／Q&A” |

上表案例仅示范表达结构，不构成用户业务事实。实际创作替换为可追溯材料；虚构教学案例明确标注。

Cycling 三遍、提问等待约七秒是讲述中的启发式参考。按时长、问题难度与互动方式调整，不把次数、秒数或字号当作普适合格线。原讲述的走神比例等解释，不作为新增科学结论传播。

## 让作品被记住：选择有用的 5S

5S 是可选的记忆设计视角，不是每页必须集齐的评分表。

| 要素 | 选择标准 | 失效方式 |
| --- | --- | --- |
| Symbol／符号 | 图形或物件能指回概念关系 | 漂亮图标与论证无关 |
| Slogan／短语 | 简短、准确，便于提取核心含义 | 押韵但夸大，或只能记住品牌 |
| Surprise／意外 | 有证据的结果修正听众合理预期 | 制造震惊、选择性呈现数据 |
| Salient idea／突出观念 | 从众多想法中凸显一个易识别的认识 | 把“重要”误当“有辨识度”，堆满同等强调的观点 |
| Story／故事 | 具体呈现问题、选择及结果，让因果可跟随 | 趣闻抢走注意力，听完不知道支持什么 |

核心主张是论证中心，salient idea 是突出的认识，两者可以重合。选能解释内容的最小组合，让抓手在关键论证和结尾再次出现；每次出现都帮助提取新的依据或应用。

检验：拿掉装饰，能否一句话说出所得？只看到抓手，能否回想主张及依据？若观众只记得故事人物，补强故事与结论的桥接，或换抓手。代理可检查联系是否清楚，真实延迟回忆仍需听众测试。

## 按目标选结构

- **教学**：已有认知 → 新概念 → 正例与近似反例 → 应用问题 → 可复用方法。承诺是“能做什么”。
- **决策汇报**：待决问题 → 判断标准 → 证据与选项 → 代价和风险 → 建议及请求。承诺是“能依据什么作决定”。
- **产品介绍**：用户任务 → 当前障碍 → 方案如何改变过程 → 可核验效果与限制 → 适用条件。承诺是“理解价值及是否适合”。
- **研究成果**：问题与意义 → 方法和区别 → 已完成工作与证据 → 贡献及边界。求职报告的特定结构只在相应场景使用。

这些是起点而非固定章节。混合场景先确认主目标；支持它的次目标保留，争夺主线的内容移入备注或删除。
