# Patrick Winston 的演讲原则

## 1. 开场

不要以笑话开头。用赋能承诺开场：明确告诉受众结束时会知道或能做到什么。不要用“感谢邀请”、道歉或冗长自我介绍拖延承诺。

## 2. 结尾

最后一页是“贡献”，列出你具体做成的事情，以及受众现在拥有的能力。不要以“谢谢”“问题？”或合作者名单收尾；合作者放在开头。可用致敬、笑话或明确行动号召结束。

## 3. 让观点留下——Winston 之星

每个重要观点应有五个 S：**符号**（视觉锚点）、**口号**（可复述短语）、**惊喜**（违反假设）、**醒目观点**（唯一突出要点）和**故事**（它如何发生、如何运作、为何重要）。

## 4. 说服的结构——愿景、工作证明、贡献

前 5 分钟建立愿景和做成了事情。列出达到目标的步骤，标明已完成步骤；结尾列出贡献并回应开场承诺。

## 5. 道具与教学

实体道具令人难忘。教学时渐进揭示，匹配受众吸收速度；展示时才使用完整幻灯片。使用近失例解释边界。

## 6. 幻灯片原则

幻灯片是佐料，不是主菜。少文字、清晰层级、不要朗读；每页一个观点。避免密集文字、重复、装饰性背景和最后的“谢谢”页。必要时将细节放进演讲者备注。
