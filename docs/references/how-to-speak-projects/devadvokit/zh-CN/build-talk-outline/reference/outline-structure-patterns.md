# 演讲提纲结构模式

## 模式 1：问题 → 诊断 → 方案

适合需要说明问题、解释根因并提出解决方案的演讲。先陈述受众关心的问题，再展示证据和诊断，最后给出方案与下一步。

## 模式 2：叙事 / 案例研究

以具体人物、情境或事件为主角。按设置、冲突、尝试、转折和结果推进；回到可迁移的要点。

## 模式 3：教程 / 演练

先给赋能承诺，再按依赖顺序逐步教学。每一步包含目标、操作、结果和检查点；保留失败处理。

## 模式 4：论证 / 论题

提出可争辩论题，承认反方，依次给出证据和推理，处理最强反驳，最后给出结论和行动号召。

## 模式 5：概念介绍

从受众已知的例子或问题出发，建立边界和定义，逐步形成模型，再说明应用与限制。

## 模式 6：比较 / 决策指南

先确定决策标准，再逐项比较选项，突出关键取舍，给出适用条件和推荐。

## 按时长的时间指导

开场 2–3 分钟，结尾 2 分钟；先扣除问答时间。现场演示按估计时长增加 20% 缓冲。每节使用累计时间戳，确保留有删减余量。
