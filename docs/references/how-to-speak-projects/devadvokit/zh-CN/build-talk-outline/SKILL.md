开始任何工作前：
1. 检查 `~/.devadvokit.md` 是否存在。
2. 若存在，静默读取并贯穿使用。
3. 若不存在，停止并告诉用户：“运行此技能前我需要你的 DevRel 背景。请先运行 /setup-devadvokit。”

开始前静默读取 `reference/winston-talk-principles.md`。全程应用这些原则——它们是结构要求，不是可选润色。

## 问答

逐个提问，一次一个；每次等待回答后再继续。

1. 粘贴 CFP 摘要或演讲描述。若还没有，用几句话描述演讲：要解决的问题、采取的角度，以及希望受众带走什么。
2. 演讲格式和时长是什么？（如演讲/30 分钟、工作坊/90 分钟；包括是否有问答及通常持续多久）
3. 除一般背景外，这次受众还有什么特点？（资历构成、专业或综合活动、你知道他们在会议上看过什么）
4. 演讲位于理论到实践光谱的哪一端？理论偏重、平衡、实践偏重。
5. 是否计划现场演示？若是，描述每个演示、依赖项（网络、认证、第三方服务、本地工具）和预计时长。
6. 是否计划受众互动？（投票、举手、短练习、结对讨论等）如有请描述。
7. 时间不足时哪些内容绝不能删？
8. 希望怎样结束？（明确行动号召、开放问题、资源页、直接进入问答）

## 构建提纲

使用 CFP 材料、问答答案和 `~/.devadvokit.md` 中的演讲者背景构建提纲。生成前阅读 `reference/outline-structure-patterns.md`，为演讲类型和格式选择最合适的结构模式。

### 时间规则

- 用户表示有问答时先预留问答时间：30 分钟通常 5 分钟，45–60 分钟通常 10 分钟，除非用户另有说明。
- 开场固定 2–3 分钟，结尾固定 2 分钟。
- 现场演示在用户估计上增加 20% 缓冲；演示总是比预期更久。
- 若用户描述的内容放不进格式，明确标记并建议删减或延后，不要默默压缩全部内容。

### 章节格式

按结构化序列呈现。每节使用：

```
[开始时间–结束时间] 章节标题
内容备注：本节发生什么、覆盖哪些要点
类型：[概念 / 演示 / 互动 / 过渡 / 结尾]
```

使用从 0:00 开始的累计时间戳，精确写“5:00–9:00”，不要写“约 5 分钟后”。

## Winston 要求——应用于每份提纲

阅读 `reference/winston-talk-principles.md`，完成以下结构检查。

### 开场

开场必须包含赋能承诺：写明结束时受众能做到而现在不能做到的具体事情，并且足够具体，使受众能判断承诺是否兑现。若用户描述的开场包含笑话、“感谢邀请”、道歉，或承诺前过长自我介绍，应标记并移除。

### Winston 之星——记忆点

在相关章节的内容备注中安排：**口号**（核心观点的抓手；若没有自然产生则建议候选）、**惊喜**（挑战受众假设的反直觉点）、**醒目观点**（唯一要点；若有多个则标记记忆会更困难）、**符号**（代表核心观点的具体视觉/实体物体）。

### 结构检查

若演讲具有说服性，前 5 分钟建立愿景；每节必须推进愿景或提供工作证明，不属于二者的章节是删减候选。

### 结尾

结尾必须以贡献页结束，写明受众现在拥有而进场时没有的东西，并直接回应开场承诺。若用户描述最后一页为“问题？”或“谢谢”，标记它。

### 幻灯片密度检查

根据章节数和内容估计幻灯片数量；30 分钟超过 20 页即为警告，并指出最可能产生密集幻灯片的章节。

## 演示风险评估

对问答中识别的每个现场演示，在其章节后立即生成风险块，并读取 `reference/demo-risk-patterns.md` 评估：

```
⚠️ 演示风险：[演示名称]
风险级别：[低 / 中 / 高 / 严重]
依赖项：[演示需要的内容]
失败模式：[最可能出错的地方]
备用方案：[具体备用方案]
准备检查表：[演讲前要做什么]
```

备用层级依次为：1. 前一天录制成功视频；2. 带讲解的截图；3. 代码走读；4. 仅低复杂度演示可用的口头描述。每个风险块必须说明中途失败时演讲者该说什么，把失败框定为具有启发性的示例，并明确需要提前准备的备用方案。

## 风险摘要

完整提纲后输出总体风险级别（依据现场演示数量、依赖比例和失败后可保留的内容）、关键路径、时间风险（具体建议删哪节多少时间）以及一段具体可执行的应急方案。

## 输出顺序

1. 带 Winston 注释的时间戳结构化提纲
2. 演示风险块（紧跟相关章节）
3. 风险摘要
4. 提供：“要我调整平衡、重构某节，或为任一部分展开演讲者备注吗？”

展示前读取 `../../shared/ai-antipatterns.md`，静默改写其中标记的模式，不要向用户提及这一步。
