# 如何演讲 — Winston 启发式写作 / 演讲 / 视频脚本工具

来源：Patrick Winston, MIT OCW "如何演讲" (IAP 2018)。原文是 1 小时讲座，这里抽成可复用的清单与流程。
双语：中文为主，英文术语保留作为可索引锚点。

## 何时启用

- 写一篇**长文 / 技术博客 / 专栏**：需要结构化、能让人读到结尾
- 写一段**视频口播稿 / 短视频脚本**：节奏、钩子、停顿
- 准备一次**演讲 / 答辩 / 技术分享 / 工作面试 演讲**：开场、中段、收尾
- **审视/优化已有文稿**：检查"信息密度、记忆点、CTA"

不适用于：闲聊文案、纯技术参考文档（无叙事）。

## 核心心法（One-Language-Processor）

人只有一台语言处理器——**要么读，要么听，不能同时**。所有规则都从这条出。

## 三段式工作流（写作 / 演讲 / 视频通用）

### ① 起：Empowerment Promise 赋能承诺（不开玩笑）

- ❌ **不要**用 joke / 段子开场（听众还在适应你的声音参数）
- ✅ 用 **promise**：结束时听众能知道 / 做到他们现在不知道 / 做不到的事
- ✅ 同步点出 **passion**：你为什么 care（passion 比 promise 更难伪造）
- 模板：「到 [时间点] 你会 [具体收获]，而且其中至少 [N] 点会让你想立刻去用」

### ② 承：四个常驻启发式（写作 = 替读者"骑三轮车"）

| # | 启发式 | 写作落地 | 视频 / 演讲落地 |
|---|---|---|---|
| 1 | **Cycling** 循环（任何时刻有 20% 读者/听众 fog out） | 关键结论出现 **≥3 次**：开篇点出、正文展开、结尾回收 | 关键观点讲 3 遍：开宗明义 → 举例 → 重述 |
| 2 | **Fence** 围栏（区分你 vs 他人） | 显式比较：「和 X 的方法不同，我是……因为……」 | "X 是 exponential, mine is linear" 一句话打边界 |
| 3 | **Verbal Punctuation** 言语标点（让掉队者随时"上车"） | 用 **序号 / 小标题 / 锚句**（"第三点""最后一个原则"） | "首先... Second... Third..."；预告下一个小节 |
| 4 | **Question** 提问 + 等 7 秒 | 在每个大节后留一个**让读者自问自答的练习题** | 抛问题 + 沉默 ≥7 秒（不会真死的） |

### ③ 收：Final 幻灯片 / Final Paragraph ≠ 客套

- ❌ 不要 "Thanks for reading/listening"（暗示大家出于礼貌才留到这）
- ✅ Final paragraph / slide = **Contributions 镜像开头**
  - 开篇提 problem → 收尾列你**实际给出的东西**（steps、takeaway、checklist）
- ✅ 收尾三选一：**joke**（节奏允许时）/ **致敬读者**（"我希望这对你有用"）/ **benediction**（一句格言、call back、回头呼应开头）

## 工具选择：Boards vs Props vs 幻灯片

| 目的 | 工具 | 理由 |
|---|---|---|
| 教（teach / inform） | 黑板 / 手写 / 实物 prop | 镜像神经元 — 观众感觉自己在做 |
| 说服 / 展示（persuade / expose） | 幻灯片 | 控制节奏，便于远端观看 |

**Empathic Mirroring** 是 Winston 给出的根本理由：人在看到他人书写/操作时，镜像神经元会让观众产生"我也做了"的体感——这就是为什么 prop 比图强、黑板比 PPT 强。

## 幻灯片（如果用）七戒

1. **不要读幻灯片**（听众识字，浪费注意力）
2. **字少**（每张 ≤ 一句话核心）
3. **字号 ≥ 40pt**（小字是「塞太多」的借口）
4. **无背景、无 logo、无标题**
5. **无激光笔**（破坏眼神交流）；用箭头标数字
6. **最多一张密集页**（epex Lan，整场只能用一次）
7. **打印出来放桌上自检**（一眼看出"太重 / 缺空气 / 缺图"）

## 让作品被记住：Winston Star (5S)

让你的**观点 / 品牌 / 个人风格**被记住，五项里至少占三项：

1. **S**ymbol — 一个具象符号（拱门 / 钢球 / 一把刀）
2. **S**logan — 一句口号（"one-shot learning"）
3. **S**urprise — 反直觉的发现（"you can learn with one example"）
4. **S**alient idea — 一个"卡住"的概念（near miss）
5. **S**tory — 完整故事（人物 + 转折 + 教训）

## 场景速查

| 场景 | 强约束 |
|---|---|
| **文章写作** | Cycling ≥3；Fence 显式比较；小标题当 Verbal Punctuation；Final = Contributions 清单 |
| **视频文稿** | Promise + Passion 必须在前 30s；prop / 实物 > 字幕；每 3-5 分钟一个 Cycling 回收点 |
| **公开演讲 / 答辩** | 5 分钟内亮出 **Vision + Done something**；用不熟悉你工作的朋友彩排 |
| **技术分享** | Story-form：problem → approach → steps → contributions；Winston Star ≥3 项 |

## 工作流（自检清单）

写完 / 讲前逐项打勾：

- [ ] 开场是 **promise** 不是 joke
- [ ] 关键观点**至少出现 3 次**（开头 / 中段 / 结尾）
- [ ] 我的观点与"竞品/常见误解"有显式区分（Fence）
- [ ] 用序号 / 小标题 / 锚句让读者随时能跟上（Verbal Punctuation）
- [ ] 结尾是 **Contributions 镜像** + joke/致敬/benediction 三选一，非"Thank you"
- [ ] Winston Star ≥ 3 项（symbol / slogan / surprise / salient / story）
- [ ] 幻灯片（若有）过七戒
- [ ] 工具选择对路：teach→黑板/prop，persuade→slides
