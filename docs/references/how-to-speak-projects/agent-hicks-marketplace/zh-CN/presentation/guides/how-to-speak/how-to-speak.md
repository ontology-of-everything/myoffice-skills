# 如何说话

**Patrick Winston，麻省理工学院** -- 麻省理工学院“如何说话”IAP 会议的演讲稿。

温斯顿的论点是：你人生的成功很大程度上取决于你的演讲能力、写作能力以及你的想法的质量——按顺序排列。沟通质量遵循一个公式：**知识+实践+天赋**，其中天赋是最小的因素。最重要的是你对演讲的了解。

> **想要完整的故事吗？** 下面的每个部分在 [`how-to-speak-transcript/`](how-to-speak-transcript/) 中都有相应的原始记录，其中包含温斯顿的完整文字、轶事和示例。

## 如何开始

**不要从笑话开始。** 一开始，人们仍在适应并适应你的声音参数。笑话平淡无奇。

**从授权承诺开始。** 告诉人们他们最终会知道他们在开始时不知道的事情。这就是他们在那里的原因。

> “在这 60 分钟结束时，你将了解一些你现在不知道的关于演讲的事情，而这些事情中的某些事情将会改变你的生活。”

---

## 吸引观众的四种启​​发法

### 1. 循环

多次围绕这个主题。并不是因为你的听众不聪明——在任何特定时刻，大约 20% 的人都会被迷惑。骑自行车确保每个人得到它的概率都很高。

### 2. 建造栅栏

将您的想法与他人的想法区分开来。 “我的算法可能看起来与琼斯的算法相似，只是他的算法是指数算法，而我的算法是线性算法。”击剑可以防止你的想法与他人的关系产生混淆。

### 3. 口头标点符号

提供人们可以返回巴士的标志性时刻。枚举。公布结构。 “第一个想法是骑自行车。第二个想法是建造栅栏。现在第三个想法是口头标点符号。”谈话中的接缝让人们重新参与进来。

### 4. 提出问题

精心挑选的问题重新吸引观众。你可以等待大约 7 秒的沉默才能得到答案——这感觉就像永恒，但却是标准。问题不能太明显（令人尴尬）或太难（沉默）。

## 时间和地点

**最佳时间：** 上午 11:00。大多数人都是醒着的，没有人会回去睡觉，尤其是饭后。

**照明：** 保持灯亮。昏暗的灯光表示睡眠。 “闭着眼皮很难看到幻灯片。”

**检查房间。** 提前参观该空间以应对任何意外情况。温斯顿想象座位上挤满了“无私的农场动物”，所以没有什么比预期更糟糕的了。

**调整房间大小。** 已满一半以上。偌大的大厅里十个人，让所有人都想知道到底出了什么问题。

## 行业工具

### 黑板（黑板/白板）

最适合**告知**——教学、演讲。

三大美德：
1. **图形质量** -- 您可以自然地绘制、图表、可视化
2. **速度** -- 书写速度与人们吸收想法的速度相匹配（幻灯片翻转太快）
3. **目标** -- 让您可以用手做一些事情。新手演讲者突然意识到他们的手。即使您所指的内容并不直接相关，指向白板也会产生参与感

**移情镜像：**当观看某人在黑板上写字或操纵物理物体时，镜像神经元就会激活。观众感觉自己在这么做。这就是为什么看板和道具比幻灯片更有吸引力——你需要在现实世界中看到它。

**适应缩放/虚拟：** 您无法走到虚拟演示中的黑板前，但您可以使用 **黑板序列幻灯片** 来模拟它——两张背对背的幻灯片，逐渐显示绿色黑板背景上的图画。这些与您精心设计的幻灯片是分开的（有意的模式切换，而不是混合插图）。请参阅 [`chalk-board.md`](chalk-board.md) 了解使用 Nano Banana 的工作流程。

### 道具

剧作家是道具知识的保管人。在易卜生的《海达·加布勒》中，一个火势越来越大的大肚炉子和一份手稿造成了难以忍受的紧张——你知道手稿即将被投入火中。

道具是令人难忘的。吉姆·格拉斯 (Jim Glass) 记得 20 年后的一次演讲，因为“那次演讲让你弄坏了指针。”

**示例：** 带有胶带的旋转自行车车轮比任何方程都更好地教导陀螺仪进动。只考虑胶带下面的部分，而不是整个轮子。

**示例：** 艾伦·拉扎勒斯 (Alan Lazarus) 将头靠在墙上，释放了一个摆球 - 它摆动起来，然后又回来，勉强亲吻了他的鼻子。几秒钟的“这家伙真的相信能量守恒”。 （不要在家里尝试这个——自然的倾向是推动，而不仅仅是释放。）

### 幻灯片

最适合**暴露**想法（工作演讲、会议演讲）——而不是教授它们。

**普遍真理：** 总是有太多的幻灯片和太多的文字。

**要避免的犯罪：**

|犯罪|修复|
|-------|-----|
|字数太多|减少到必要的短语。小字体=太多字。最低~40pt。 |
|扬声器远离幻灯片|靠近你的视觉材料。避免网球比赛中的回头率。 |
|大声朗读幻灯片 |您的观众可以阅读。阅读会侮辱他们并浪费你的声音。 |
|背景杂乱|删除徽标、装饰元素、不必要的标题。 |
|激光笔|你转过身去，失去目光接触。请改用幻灯片上的箭头。 |
|太重了|打印幻灯片，放在桌子上。如果没有空气/空白，它就太重了。 |

**语言处理器问题：** 人类只有一种语言处理器。包含大量文字的幻灯片迫使人们阅读而不是聆听。在一项实验中，学生们对幻灯片上内容的记忆比对演讲者所说内容的记忆要好。其中一个主题是：“我希望你不要说太多，这会分散你的注意力。”

**Hapax Legomenon：** 一张如此复杂的幻灯片，故意让人难以理解——这就是重点（例如，阿富汗治理复杂性图）。每次演示您都会得到一份。

## 激励观众

温斯顿对麻省理工学院的人们进行了调查，了解激励他们的因素：

- **新生：** 受到告诉他们可以做到的老师的启发
- **高级教员：** 受到帮助他们以新方式看待问题的人的启发
- **每个人：** 受到对自己所做的事情表现出**热情**的人的启发

表达某件事有多酷。表现出真正的兴奋。

**示例：** 一种着色算法所需的时间比太阳系的寿命还要长，但只需进行一次调整，即可在几秒钟内完成。 “这不是很酷吗？”

## 教人们如何思考

我们是讲故事的动物。我们通过专业学校及其他领域培养童话故事的故事技能。教人们思考意味着提供：

- 他们需要了解的故事
- 关于这些故事的问题
- 分析故事的机制
- 将故事放在一起的方法
- 评估故事可靠性的方法

## 说服：口试

人们口语考试失败的最常见原因是：**未能定位**。将您的研究置于特定背景下——什么问题、未解决的时间、为什么重要、会产生什么影响。

**与合适的人一起练习。**不是办公室同事或你的顾问——他们了解你的工作，并且会产生幻觉，这些材料在你的演示文稿中，但实际上并非如此。与不了解您工作的朋友一起练习。告诉他们：“如果你不能让我哭，我就不会再把你当作朋友了。”

**难度与年龄成正比。**年轻的考官试图证明他们有多聪明。高级审查员了解他们在世界上的位置。更喜欢你的委员会中有白头发的人。

## 说服：工作谈话

温斯顿询问了两位同事——多洛雷斯·埃特（Dolores Etter）（21 本书）和比尔·韦尔登（Bill Weldon）（轨道炮穿过坦克装甲）——他们在教师候选人中寻找什么：

- **多洛雷斯：** “他们必须向我们展示他们有某种愿景。”
- **比尔：**“他们必须向我们展示他们已经做了一些事情。”

**他们还有多长时间？** 五分钟。如果你没有在五分钟内表达你的愿景并展示成就，你就已经失败了。

＃＃＃ 结构

1. **愿景** = 有人关心的问题 +
方法中的新内容 2. **完成某事** = 列举实现解决方案所需的步骤。你不必完成所有这些：“这就是需要做的事情。我们需要指定行为，枚举约束，实现一个系统 - 我们已经构建了这样一个系统，我们即将演示它。”
3. **内容**（演讲的主体）
4. **贡献** = 步骤的镜像，确定您已完成的工作

## 成名（让你的工作得到认可）

朱莉娅·柴尔德 (Julia Child) 谈名声：“你会习惯的。”但你永远不会习惯被忽视。

> “你的想法就像你的孩子，你不希望他们衣衫褴褛地来到这个世界。”

### 温斯顿之星（5 S）

每个元素都始于 S. Winston 的关于拱门学习的博士论文，意外地拥有了所有五个元素，这就是它变得众所周知的原因：

|元素|描述 |拱门示例 |
|---------|-------------|-------------|
| **符号** |与您的作品相关的视觉效果/图标 |拱门本身|
| **口号** |提供句柄的短语 | “一次性学习”|
| **惊喜** |意想不到的事情 |你不需要一百万个例子|
| **突出的想法** |一个突出的想法（不仅重要——突出）| “未遂事件”的概念 |
| **故事** |你是如何做到的，它是如何运作的，为什么它很重要 |从例子中学习的叙述|

一篇包含太多好想法的论文可能会失败，因为没有一个是突出的。你需要一个突出的想法。

## 如何停止

### 最后一张幻灯片

|幻灯片类型|判决 |为什么 |
|-----------|---------|-----|
|长长的合作者名单|坏|表明没有人知道谁做了重要的工作。将协作者放在**第一张**幻灯片上。 |
| “问题？” |坏|可以熬夜20分钟。挥霍房产。 |
| “谢谢”|坏|浪费机会。 |
| “结局”|坏|浪费机会。 |
| “结论” |平庸|人们并不关心结论。他们关心你**做了什么**。 |
| **“贡献”** | **最好** |列出您所完成的工作。问答期间熬夜。告诉人们你是谁。 |

### 最后的话

|结束|判决 |笔记|
|--------|---------|--------|
|一个笑话|好 |演讲结束时，听众已经适应了你的声音。道格·莱纳特：“我总是以一个笑话结束——这样人们就会认为他们一直玩得很开心。” |
| “谢谢”|弱|暗示观众出于礼貌而离开并想去其他地方。 |
|祝福|好 | “上帝保佑你，上帝保佑美国”（政治演讲）。 |
|向观众致敬|好 |表达你多么珍惜和他们在一起的时间。 “看到你们所做的事情真是令人着迷……” |

**你不必说“谢谢”。** 一旦掌声开始，你可以把它说出来，但这不应该是你最后故意说的话。有一些惯例标志着结束：在天主教弥撒中，“Ite, missa est”（弥撒结束，你可以回家了）；在音乐会上，指挥与首席握手。

## 快速参考：温斯顿规则

1. 从授权承诺开始，而不是笑话
2. 围绕您的主题循环（说三遍）NLSEP 3. 围绕您的想法建立围栏
4. 使用口头标点符号（列举、宣布结构）
5. 提出精心挑选的问题（等待 7 秒）NLSEP 6. 上午 11 点，房间光线充足，大小合适，提前布置
7. 教学板，展示幻灯片NLSEP 8. 道具能产生同理心镜像，令人难忘
9. 幻灯片：更少的文字，更大的字体，没有激光笔，消除混乱
10. 表现出激情——这是普遍的灵感信号
11. 工作演讲：愿景 + 完成的事情，5 分钟内建立
12. 温斯顿之星：象征、口号、惊喜、突出的想法、故事
13. 最后一张幻灯片 =贡献（不是合作者、问题或谢谢）
14. 结束语 = 笑话、祝福或致敬（不是“谢谢”）
