# 演示风格指南（默认）

除非用户另有指定，否则所有演示均使用此样式。

## 幻灯片类型和背景

三种具有不同背景的幻灯片类型：

|类型 |背景|用于 |
|------|------------|---------|
| **标题/部分** |  `assets/backgrounds/dark.png`（有机波浪深海军蓝）|标题幻灯片、分区分隔线、结束幻灯片 |
| **插曲** |  `assets/backgrounds/light.png`（浅蓝灰色有机波）|过渡幻灯片、引用幻灯片、视觉中断 |
| **内容** |纯白色`{ color: "FFFFFF" }`|所有内容幻灯片（幻灯片的大部分内容）|

**在代码中加载背景：**
```javascript
const fs = require("fs");
const SKILL_DIR = "${CLAUDE_PLUGIN_ROOT}/skills/presentation";
const darkBg = "image/png;base64," + fs.readFileSync(`${SKILL_DIR}/assets/backgrounds/dark.png`).toString("base64");
const lightBg = "image/png;base64," + fs.readFileSync(`${SKILL_DIR}/assets/backgrounds/light.png`).toString("base64");

// Title slide
slide.background = { data: darkBg };
// Interlude slide
slide.background = { data: lightBg };
// Content slide
slide.background = { color: "FFFFFF" };
```

## 调色板

|角色 |十六进制 |用途 |
|------|-----|--------|
|小学| `1E2A5E`|白色背景、卡片、口音上的标题 |
|口音| `E04040`|字幕、亮点、关键数字 |
|文字| `1E293B`|白色背景上的正文|
|静音 | `4A5568`|辅助文本、标题、项目符号 |
|浅色文字| `CADCFC`|深色背景上的文字 |
|白色| `FFFFFF`|深色背景上的主要文本 |

## 内容幻灯片设计

内容幻灯片使用**干净的白色背景**。通过以下方式添加视觉兴趣：

- **海军蓝口音卡**（`1E2A5E` 填充）用于统计标注或关键点
- **间奏幻灯片上带有阴影的白色卡片**用于对比
- **左对齐文本**用于所有正文内容；仅居中标题
- **图表和表格**使用上面的调色板

**布局选项：**
- 两列（左侧文本，右侧视觉）
- 图标 + 文本行
- 2x2 或 2x3 卡片网格
- 带描述的大型统计标注

**数据显示：**
- 大统计数字（60-72pt），下方带有小标签
- 比较列（之前/之后，并排）
- 时间线或流程

## 间距

- 距离幻灯片边缘 0.5 英寸最小边距
- 内容块之间 0.3-0.5 英寸
- 留出喘息空间 - 不要填满每一英寸

＃＃ 避免

- **不要重复相同的布局** -- 改变幻灯片中的列、卡片和标注
- **不要将正文居中** -- 左对齐段落和列表；仅居中标题
- **不要在标题下使用重音线** -- 使用空格代替
- **不要使用低对比度元素** -- 测试背景的可读性
- **不要忘记文本框填充** -- 与形状对齐时设置`margin: 0`NLSEP - **不要随机混合间距** -- 选择 0.3 英寸或 0.5 英寸间隙并一致使用
