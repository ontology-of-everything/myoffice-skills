# 演示文稿制作

从材料制作有依据、能理解、可记忆的 HTML 或 Markdown 演示文稿。流程涵盖理解、头脑风暴、塑形、大纲、创作及检视重构，关键方向对齐后再开展依赖它的工作。

默认单文件 HTML、现场演示配讲者备注；支持完整 Markdown 与独立阅读模式。单份轻量记录保存决策和来源位置。技能不附带脚本，不依赖其他技能。

```text
$presentation-making-cn 根据这些材料制作一份 15 分钟分享，帮助听众理解并记住一个可应用的核心主张。
```

仅保留中文版，默认不自动调用。Codex 使用 `$presentation-making-cn`，Cursor 使用 `/presentation-making-cn` 显式调用。本技能统领证据、叙事、记忆设计与重构，并按交付需要制作 HTML 或 Markdown 文稿。
