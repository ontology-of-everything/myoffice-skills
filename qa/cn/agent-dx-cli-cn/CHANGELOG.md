# agent-dx-cli-cn 变更记录

## 0.3.0 — 2026-10-14

- 明确技能决策辅助与 CLI 执行契约的边界，保留任务范围及证据条件。
- 清理过时和噪声指令，以无技能表现为基线检验实际收益。

## 0.2.0 — 2026-10-12

- 用独立参考文档增加可选的 SKILL+CLI 编写规范。
- 以固定版本实例保留 GWS 共用、服务、辅助命令、任务流程和角色语义。
- 区分 GWS 原始组织和 Space 改编。增加编写与范围验证。
- 保留 CLI 主流程、评分门槛和显式调用。

## 0.1.2 — 2026-10-12

- 将 GWS 参考改为命令与验证动作，固定来源移到文末。
- 将安全验证并入主技能正反例，删除独立安全示例文件。
- 用短句、明确动作和一致术语精炼中英文配套。
- 保留十维检查、评分门槛和显式调用。

## 0.1.1 — 2026-10-12

- 增加幂等、本地预演、未知结果、完成边界和契约漂移的精炼示例。
- 验证服务端 key 作用域、保留期、冲突处理及持久业务效果。
- 主技能保持精炼，详细示例按需读取。
- 保留手动调用、评分标准和安全门槛。

## 0.1.0 — 2026-10-12

- 将同一维度的检查标准命名为检查点 1/2。说明本地评分约定，检查标准与权重保持一致。

- 采用已确认的平衡执行版。按用户要求保留版本 0.1.0。

- 初始版本：手动调用，指导 CLI 开发、审查和重构。
- 三项原则：可预测性、纵深防御、上下文效率。
- 十维、20 项证据评分，关键安全问题阻断验收，并固定 GWS 参考版本。
- 独立审查在既有 CLI 中发现严格 JSON、预演状态和 schema 缺陷。
- 本轮仅选择英文包发布到 ClawHub；中文版保留源码与 Codex 安装。
