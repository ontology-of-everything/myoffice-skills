# Behavioral assertions

Judge observable actions and cited evidence, not heading matches. Check request scope, source accuracy,
role-aware validation, no production side effects, honest scoring, and minimal justified changes.
Forward evaluators receive prompts and raw artifacts, not expected answers. Record failures before making narrow fixes.

配套技能验证检查可用命令、条件加载、原生语义和完成边界。
对实际 CLI 核对 dry-run 声明。普通 CLI 审查不得擅自创建配套技能。

0.3.0 增加 `harmful-companion-skill` 场景，以无技能表现为对照并记录实际结果与上下文成本。新增场景不代表行为测试已通过。
