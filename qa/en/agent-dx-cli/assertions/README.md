# Behavioral assertions

Judge observable actions and cited evidence, not heading matches. Check request scope, source accuracy,
role-aware validation, no production side effects, honest scoring, and minimal justified changes.
Forward evaluators receive prompts and raw artifacts, not expected answers. Record failures before making narrow fixes.

For companion skills, inspect usable commands, conditional references, native semantics, and completion boundaries.
Check dry-run claims against the actual CLI. Ordinary CLI review must not create companion skills without a request.

For 0.3.0, evaluate `harmful-companion-skill` against a no-skill baseline; record actual outcomes and context cost. An added scenario is not evidence of a passed behavioral test.
